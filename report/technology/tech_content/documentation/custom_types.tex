\subsection{Custom types}

In the web application, we implemented TypeScript types to establish a robust and consistent connection with the data
stored in Supabase. By defining types that correspond to the structure of the database tables, we ensure type safety
throughout the application, thereby mitigating the risk of runtime errors and enhancing code reliability. Furthermore,
TypeScript’s object-oriented approach contributes to the codebase’s readability and organization, facilitating both
development and future maintenance efforts. For instance We created
\begin{itemize}
    \item \texttt{Article}: represents a yoga article
    \item \texttt{Course}: represents a yoga course offered by the center
    \item \texttt{CourseEnrollment}: represents the relation between a course and a student
    \item ...
\end{itemize}
