\subsection{Librairies}

This project employs two prominent external libraries: \textbf{Supabase} and \textbf{Tailwind CSS}. Supabase serves as a
backend-as-a-service solution, providing a comprehensive authentication system (encompassing sign-up, login, and
session management) and CRUD functionalities to interact with the underlying \textbf{PostgreSQL} database.
Concurrently, Tailwind CSS is utilized for user interface design. Its utility-centric approach enables the
efficient construction of responsive and consistent layouts by applying pre-defined utility classes directly within
the HTML markup. This approach facilitates precise control over styling while maintaining a clean and maintainable
codebase.
