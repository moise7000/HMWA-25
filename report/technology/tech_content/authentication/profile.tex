\subsection{Profile}

The \textbf{Profile Management section} offers comprehensive user account customization capabilities. Users can update
their personal information including first name, last name, email address, phone number, and physical address through
dedicated input fields. A sophisticated image management system allows users to upload, modify, or delete their profile
picture with real-time preview functionality. The system handles file validation (image type and size restrictions),
automatic image optimization, and secure storage using cloud-based solutions. All profile changes are saved through an
integrated save mechanism that provides immediate feedback via toast notifications for successful updates or error
handling.
