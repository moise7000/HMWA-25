\subsection{Comments}
In the \textbf{Comments Management section}, authenticated users can interact with their enrolled courses through a
feedback system. Users can select from their enrolled courses via a dropdown menu, compose detailed comments or reviews,
and submit them to share their learning experience. The interface provides real-time validation, ensuring users can only
comment on courses they are actively enrolled in. Additionally, users maintain full control over their feedback, with the
ability to view all their previously submitted comments in a structured grid layout and delete any comment using an
intuitive delete button with confirmation dialog to prevent accidental removals.
